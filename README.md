VSRP — Frontend Machine Test

A responsive frontend website developed as part of a frontend developer machine test.

The website presents a rubber manufacturing company and includes sections for services, industries, projects, manufacturing process, FAQs, insights, and contact.

Live Demo

[https://vsrp-machine-test.vercel.app/]

Tech Stack

* React
* Vite
* Tailwind CSS
* JavaScript

Features

* Responsive design
* Reusable React components
* Responsive navigation
* Hero background video
* Interactive industry sections
* Process step animation
* Horizontal project carousel
* FAQ accordion
* Hover and scroll interactions
* Mobile-friendly layouts
* Accessibility and reduced-motion support

Getting Started

Clone the repository and install the dependencies:

npm install

Run the development server:

npm run dev

Build for production:

npm run build

Preview the production build:

npm run preview
